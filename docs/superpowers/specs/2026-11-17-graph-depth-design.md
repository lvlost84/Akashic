# 그래프 입체 효과 + 연결 수별 점 크기 설계

상태: 승인 대기 (2026-11-17)

## 의도와 이유
Obsidian 소개 그림처럼 그래프가 입체적으로 보이게 하고, 노드 모양(▲■◆) 대신 점 크기로 연결 수를 보여 준다.
모양과 크기가 같은 정보(연결 수)를 이중으로 표시해 혼란스럽고, 지금은 크기 차이도 작아(최대 약 3배) 허브가 눈에 띄지 않는다.
위치 계산·클릭·끌기는 2D 그대로 두고, **그릴 때만** 깊이를 더한다.

## 목표
- 모든 노드를 원으로 그리고, 연결이 많을수록 확실히 크게 한다.
- 마우스를 움직이면 그래프가 입체적으로 반응한다(방식 A 시차 + 방식 B 기울임 원근, 둘 다).
- 노드를 구슬처럼(하이라이트) 그리고, 먼(연결 적은) 점은 조금 작고 흐리게 그린다.
- 옵션 "입체 효과" 슬라이더(0 = 끔, 끄면 지금의 2D와 같은 결과).

## 비목표 / 하지 말 것
- 진짜 3D 배치·끌어서 회전·WebGL은 하지 않는다. 물리 배치는 2D 그대로.
- 이전 설정 파일이 깨지면 안 된다. 입체 효과가 클릭 정확도를 떨어뜨리면 안 된다.
- 마우스가 멈춘 상태에서 CPU를 계속 쓰지 않는다(움직임이 가라앉으면 다시 그리기를 멈춘다. 기존 "잔잔한 움직임"은 그대로).

## 접근 (선택: A + B 함께)
- A 시차: 마우스 위치만큼 깊이에 비례해 점을 화면에서 밀어낸다(앞 점이 더 많이). 가볍다.
- B 기울임: 깊이를 가진 점들을 마우스 위치에 따라 최대 약 ±12° 회전시킨 뒤 원근 투영한다(앞 점이 더 크게).
- 둘은 같은 깊이 값(z)을 쓰므로 함께 구현해도 추가 비용이 작다. A만 쓰거나 B만 쓰는 선택은 슬라이더 하나로 합쳐 둔다(강도).

## 설계(내 판단 포함)
- 깊이 z ∈ [-1, 1] = `2·sqrt(deg / 최대 deg) − 1` (최대 deg 0이면 0). 중심 노드는 +1.  *(내 판단)*
- 마우스 위치 p ∈ [-1, 1]²(그래프 영역 중심 기준)를 프레임마다 0.12씩 따라가게 부드럽게 한다. 영역 밖이면 0으로 돌아간다.
- 투영(월드 좌표 기준, 이동·확대 전): z를 `Z_UNIT`(120)만큼 펴서 x/y축으로 `±12°·강도·p` 회전 → 원근 계수 `s = D/(D − z′)` (`D`=900) → 위치·반지름에 곱한다. 시차: 화면에서 `p·z·14px·강도` 추가 이동.
- 반지름: `4.5·node_size·min(1 + 0.6·sqrt(deg), 5.0)` (연결 0=1배, 4=2.2배, 9=2.8배, 25 이상=4배, 상한 5배·지름 약 45px). 중심은 ×1.3. 옵션 "연결이 많을수록 크게"는 유지(끄면 같은 크기).
- 그리기: 원(또는 점선 원) + 왼쪽 위 하이라이트(작은 밝은 원), 먼 점은 색을 최대 25% 흐리게. 선은 투영된 끝점으로, 깊이 평균에 따라 흐리게.
- 한 프레임에 투영 결과(화면 좌표·크기 배율)를 한 번 계산해, 그리기·강조·클릭 판정·글자 위치가 모두 같은 값을 쓴다.
- 없는 문서는 점선 원, 고정(끌어 놓음) 노드는 바깥 원 테두리, 찾기 일치는 강조 원 테두리로 바꾼다.
- 글자 자리(칸) 계산은 기울임 없는 기본 위치로 하고, 실제 글자는 투영된 점 위치에 붙인다(기울임이 작아 겹침 판정 오차는 허용). *(내 판단)*
- 설정: `GraphSettings`에 `depth_fx: f32`(0..=1, 기본 0.6) 추가. `shape_mode`·`hub_links`·범례·모양 메뉴 삭제. 설정 파일은 모르는 필드를 무시하므로 옛 파일도 읽힌다. 분류별 모양은 없어지고 분류별 색만 남는다.
- 문서: 도움말(F1) 그래프 설명, README, DEVLOG, 버전 2.5.0.

## 테스트·확인
- 단위: 깊이 정규화, 반지름이 deg에 단조 증가·상한, `강도=0`이면 투영이 항등, 앞(z↑)이 더 크게, 옛 설정 파일 호환, 기존 그래프 테스트 유지(모양 테스트는 삭제).
- 화면: 마우스를 좌우로 옮긴 캡처로 입체 변화 확인, 클릭·끌기 정확도, 다크 테마.

## 빌더에게 남기는 것
세부 상수(각도·거리·시차 폭·흐림 정도), 하이라이트의 정확한 모양, 부드럽게 따라가는 계수는 화면에서 보며 조정한다.
