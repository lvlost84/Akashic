# 아카식 (Akashic)

문서를 분류와 태그로 모아 두고 빠르게 편집하는 **오프라인 마크다운 노트**입니다. 미리보기 없이 쓰는 즉시 서식이 적용되고, 모든 문서는 SQLite 파일 하나에 저장됩니다.

Rust + eframe/egui + SQLite · Windows 전용 · 설치 과정 없는 단일 `Akashic.exe`

## 주요 기능
- **실시간 서식 편집**: 제목·굵게·기울임·취소선·코드·링크·인용·목록·표·코드 블록·체크박스·가로줄이 입력하는 즉시 그 모양으로 보입니다. 커서가 있는 줄에서만 `#`, `**` 같은 기호가 나타납니다.
- **분류 트리 + 태그**: 분류는 최대 6단계 트리, 문서는 분류 하나에 속하고 태그는 여러 개를 달 수 있습니다. 끌어 놓기로 분류·태그·휴지통·순서를 바꿉니다.
- **수식**: 한 줄에 `$$\frac{a}{b}$$`처럼 쓰면 분수·첨자·제곱근·그리스 문자가 있는 수식으로 그려집니다(`\text{}` 안의 한글도 됩니다). 위아래 줄에 `$$`만 쓰면 여러 줄 수식이 됩니다(줄바꿈은 공백, `\\`는 새 줄, `\begin{aligned}…\end{aligned}`는 `&` 기준 정렬). `\dfrac` `\binom` `\sqrt[n]{}`, `\sum`·`\lim` 한계의 위·아래 배치, `\hat` `\vec` `\overline` `\boxed` `\cancel` `\overset`, `\left( \right)` 괄호 크기 맞춤, 관계·화살표·집합·그리스 문자 등 기호 300여 개를 지원합니다(쓰는 글꼴에 없는 기호는 네모로 보일 수 있음). 문법이 틀리면 원문 그대로 둡니다.
- **참고 창(새 창)**: 도구줄의 "새 창" 단추나 문서 목록 우클릭 "새 창으로 열기"로 문서를 별도 창에 읽기 전용으로 띄워 두고 보며 작업합니다(최대 8개). 본창에서 고친 내용이 바로 반영되고, 참고 창 안의 `[[문서 링크]]`를 누르면 그 창의 문서만 바뀝니다.
- **문서 링크와 연결 그래프**: `[[문서 제목]]`, `[[제목|보일 글]]`을 Ctrl+클릭으로 이동하고, 오른쪽 사이드바에서 문서 간 연결을 그래프와 목록으로 봅니다. 외부 주소(`http://…`, `C:\…`)와 각주는 문서 링크로 보지 않습니다. 표 칸 안의 `<br>`은 줄바꿈으로 보입니다. 그래프의 점은 연결이 많을수록 크고, 마우스에 따라 입체처럼 움직입니다(우클릭 설정의 "입체 효과", 0이면 끔).
- **각주**: `[^1]` 참조는 윗첨자로, `[^1]: 설명` 줄은 정의로 보이며 Ctrl+클릭으로 서로 오갑니다.
- **검색**: 제목·본문·태그 검색(SQLite FTS5), 문서 안 찾기(Ctrl+F), 목차 사이드바.
- **편집 키**: Tab/Shift+Tab 들여쓰기, PageUp/PageDown, Alt+↑/↓ 줄 이동, Ctrl+D 줄 복제, Ctrl+Shift+K 줄 삭제, 찾아 바꾸기, Ctrl+B/I 토글.
- **안전장치**: 자동 저장, 하루 한 번 자동 백업, 휴지통(30일), 동기화 저장소(512KB 조각 증분, 폴더 방식 또는 내 NAS의 WebDAV 서버에 종단간 암호화로 직접 동기화, 문서 단위 병합 방식 선택 가능), DB 정리·검색 색인 재생성.
- **꾸미기**: 라이트 / 다크 / 레이저 / 사용자 지정 테마, 영문·한글 글꼴 따로 지정, 줄·목록·문단 간격과 글자 크기 조절.
- **이미지**: 그림을 붙여넣기(Ctrl+V)·끌어 놓기·문서 메뉴 "이미지 삽입…"으로 넣으면 WebP(구글 libwebp)로 줄여 DB에 저장하고, 편집 화면에 그대로 보입니다(커서를 그 줄에 두면 `![이름](img:…)` 원문). 같은 그림은 한 번만 저장되고, 옵션에서 최대 크기·품질을 바꾸거나 쓰지 않는 그림을 정리할 수 있습니다. 전체 내보내기 때는 `images/` 폴더로 꺼내 상대경로로 연결합니다. 한 줄에 `![…](img:…)`를 공백으로 이어 쓰면(이미지 줄에 커서를 두고 넣으면 자동으로 이어 붙음) 나란히 보입니다.
- **내보내기·가져오기**: `.md` 가져오기(탐색기에서 끌어 놓기 가능), 문서·전체 내보내기.
- **자동 업데이트**: 새 버전을 확인해 내려받고, SHA256 해시가 맞을 때만 설치합니다.

## 설치
[Releases](../../releases)에서 `Akashic.exe`를 받아 실행합니다. 이후에는 앱이 하루 한 번 새 버전을 확인해 자동으로 설치하고, 다시 시작하면 적용됩니다. 옵션(Ctrl+,) > 정보에서 끌 수 있습니다.

## 기본 사용
- 새 문서 Ctrl+N, 검색 Ctrl+E, 문서 안 찾기 Ctrl+F, 찾아 바꾸기 Ctrl+H, 줄 번호로 이동 Ctrl+G, 옵션 Ctrl+, , 도움말 F1(전체 단축키 표).
- Enter로 목록·인용·체크박스가 이어지고, 빈 항목에서 Enter를 누르면 끝납니다. 링크는 Ctrl+클릭, 체크박스는 클릭.
- 뒤로/앞으로 이동 Alt+← / Alt+→, 왼쪽 목록 접기 Ctrl+\.
- 입력을 멈춘 뒤 0.8초, 문서를 바꿀 때, 닫을 때 자동 저장됩니다(Ctrl+S는 즉시 저장).

## 저장 위치
- 문서·분류·태그는 `vault.db` 하나에 있으며 기본 위치는 `문서\KnowVault\vault.db`입니다. 옵션에서 위치를 바꿀 수 있습니다.
- 설정: `%AppData%\KnowVault\config.json`, 오류 기록: 같은 폴더의 `error.log`.
- DB 폴더 자체를 클라우드 드라이브로 동기화하지 마세요(`-wal`/`-shm` 파일 때문에 꼬일 수 있음). PC 간 이동은 옵션의 **동기화 저장소**를 쓰세요.
- 표준 SQLite 파일이라 DB Browser for SQLite 등으로 열어 볼 수 있습니다.

## 빌드
```
cargo build --release     # target\release\akashic.exe
cargo test --release
```
업데이트 확인은 환경변수 `AKASHIC_REPO=사용자/저장소`가 설정된 빌드에서만 켜집니다(`.cargo/config.toml`과 GitHub Actions가 넣음). `target\` 아래의 개발 빌드는 자동으로 교체되지 않습니다.

## 릴리스 올리기
1. `Cargo.toml`의 `version`을 올립니다(예: 2.0.2).
2. 커밋 후 `git tag v2.0.2` → `git push origin main v2.0.2`
3. GitHub Actions가 시험·빌드를 거쳐 `Akashic.exe`, `SHA256SUMS`를 Releases에 올립니다.
