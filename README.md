# 아카식 (Akashic)

문서를 분류와 태그로 모아 두고 빠르게 편집하는 오프라인 마크다운 노트. Rust + eframe/egui + SQLite.
## 기본 사용
- 왼쪽 목록은 문서 제목 왼쪽의 버튼(또는 Ctrl+\)으로 접고 펼 수 있습니다. 접어도 이 버튼은 항상 보이고, 문서가 하나도 없으면 목록이 저절로 펼쳐집니다.
- 문서 목록은 제목 한 줄만 보입니다(긴 제목은 잘림, 날짜·분류·태그는 마우스를 올리면 말풍선). 제목은 문서를 **더블클릭**하거나 목록에서 **F2**(또는 우클릭 "제목 바꾸기")로 목록에서 바로 바꿀 수 있고, 오른쪽 위 제목 칸에서 고쳐도 됩니다.
- 왼쪽: 새 문서(Ctrl+N), 검색(Ctrl+E), 보기(전체 / ★즐겨찾기 / 휴지통), 분류, 태그, 문서 목록(고정됨·오늘·어제·지난 7일 … 순). 오른쪽: 제목, 태그, 본문.
- 본문은 **미리보기 없이** 쓰는 즉시 서식이 적용됩니다. 제목은 크게, 굵게·기울임·취소선·코드·링크·인용·목록이 그 모양으로 보이고, 커서가 있는 줄에서만 `#`, `**` 같은 문법 기호가 보입니다. 줄을 끝내고 Enter를 누르면 그 줄이 서식대로 보입니다.
- Enter: 목록·인용·체크박스는 다음 항목이 이어지고, 빈 항목에서 Enter를 누르면 목록이 끝납니다. 링크는 Ctrl+클릭으로 엽니다.
- 자동 저장: 입력을 멈추고 0.8초 뒤, 문서를 바꿀 때, 닫을 때 DB에 저장됩니다. Ctrl+S는 바로 저장.
- 분류(트리): 문서 하나는 분류 하나에만 속합니다. 분류는 세부 분류까지 트리로 만들 수 있습니다(최대 6단계). 왼쪽 "분류"의 +는 최상위 분류, **분류 위에 마우스를 올리면 나타나는 +는 그 아래 하위 분류**입니다. 분류를 우클릭하면 하위 분류 만들기·이름 바꾸기·다른 분류 아래로 이동·삭제(하위 분류와 문서는 한 단계 위로)가 있습니다. 같은 이름은 상위가 다르면 허용됩니다.
- 분류를 고르면 **그 분류에 직접 속한 문서만** 목록에 보이고(예: 품질 10개, 품질 > 측정기 5개면 품질을 골랐을 때 10개), 접혀 있던 하위 분류는 트리에서 열립니다. 분류 옆 숫자도 그 분류의 문서 수이고, 하위까지 합친 수는 마우스를 올리면 나옵니다. 화살표로 접고 펼 수 있고 접은 상태는 기억됩니다.
- **끌어 놓기**: 목록의 문서를 끌어서 분류에 놓으면 그 분류로 이동, **미분류**에 놓으면 분류 해제, **휴지통**에 놓으면 휴지통으로 갑니다. 분류도 끌 수 있어서 다른 분류 위에 놓으면 그 아래 하위 분류가 되고, **"분류" 머리글**에 놓으면 최상위로 올라갑니다. 탐색기에서 \.md 파일을 창에 끌어다 놓으면 가져옵니다.
- **체크박스**: \- \[ \] 할 일의 대괄호를 클릭하면 Ctrl 없이 바로 켜고 끕니다. 끝낸 항목은 글에도 취소선·흐린 색이 적용됩니다.
- **정렬과 순서**: 목록 위 오른쪽 "수정순 ▾"에서 수정순 / 만든순 / 제목순 / 직접 정렬을 고릅니다. **직접 정렬**에서는 문서를 끌어 다른 문서 위/아래에 놓아 순서를 바꿀 수 있습니다(파란 선이 놓일 자리). 고정(★)된 문서는 항상 맨 위입니다.
- 문서를 왼쪽 **태그 위에 끌어 놓으면** 그 태그가 달립니다.
- **문서 링크**: 본문에 \[\[ 문서 제목 \]\] 또는 \[\[문서 제목\|보일 글\]\] 을 쓰고 Ctrl+클릭하면 그 문서로 이동합니다(없으면 같은 분류에 새로 만듦). **Alt+← / Alt+→** 로 뒤로/앞으로 이동합니다.
- **노트 연결 그래프**: 오른쪽 위 도움말(ⓘ) 옆 아이콘이나 상태바의 "연결 N"을 누르면 \*\*오른쪽에 사이드바 \*\*가 열립니다(왼쪽 목록처럼 접고 펴고 너비도 조절 가능). 위 칸은 지금 보는 문서를 중심으로 전체 보관함이 \[\[문서 링크\]\]로 어떻게 연결돼 있는지 보여주는 그래프(마우스 휠로 확대/축소, 빈 곳 드래그로 이동, 노드를 끌어 자리 고정), 아래 칸은 스크롤되는 이 문서가 가리키는/이 문서를 가리키는 문서 제목 목록입니다. 점선 동그라미는 아직 없는 문서(눌러서 바로 만들 수 있음), 노드를 누르면 그 문서로 이동하며 그래프 중심도 따라옵니다. 문서를 바꾸면 사이드바를 열어 두지 않아도 중심이 자동으로 따라오고, 상태바의 "연결 N" 숫자(아웃링크+백링크)도 항상 지금 문서 기준으로 맞습니다.
- 옵션(Ctrl+,)은 "화면·편집 / 문서 저장소 / 백업·동기화" 세 탭으로 나뉘어 있습니다(위쪽 칸막이로 전환).
- **언어별 글꼴**: 옵션(Ctrl+,)의 "편집기"에서 **영문 글꼴**과 **한글 글꼴**을 따로 고를 수 있습니다. 한 줄에 한글과 영문이 섞여 있어도 각각 고른 글꼴로 보이고(굵게·기울임은 그대로 유지), 코드(인라인 코드·코드 블록·표)는 이 설정과 상관없이 고정폭 글꼴 그대로입니다.
- **테마**: 옵션(Ctrl+,)의 "테마"에서 **라이트 / 다크 / 레이저**(컴퓨터 주변기기 브랜드 레이저 느낌 — 거의 검정 바탕에 초록 포인트색 하나, 나머지는 무채색) 중 고르거나, **사용자 지정**으로 배경·글자·강조색 등 15가지 색을 하나하나 직접 고를 수 있습니다(편집 창의 색상 칸 클릭 → Windows 색 선택 창, 또는 16진수 직접 입력). 다른 테마의 색에서 다시 시작할 수도 있습니다. Ctrl+Alt+D는 라이트/다크만 빠르게 오갑니다.
- **미분류**는 분류 목록과 별개로 맨 위 "전체 / 미분류 / ★ / 휴지통" 줄에 항상 보이는 고정 항목입니다(문서가 0개여도 보임).
- 태그: 제목 아래 칸에 입력하고 Enter(또는 쉼표/공백). 기존 태그는 목록으로 제안됩니다. 왼쪽 태그를 누르면 그 태그의 문서만, 여러 개 누르면 모두 가진 문서만 남습니다.
- 검색: 제목·본문·태그에서 글자 그대로 찾습니다(한글 일부만 입력해도 됨, 띄어 쓴 낱말은 모두 포함). 분류·태그 필터와 함께 쓸 수 있습니다.
- 즐겨찾기(★)는 목록 맨 위에 고정, 삭제는 휴지통(기본 30일 보관 후 영구 삭제), 복제·.md 내보내기·.md 가져오기·전체 내보내기는 오른쪽 위 `…` 메뉴(또는 문서 우클릭). `.md`/`.txt` 파일을 창에 끌어다 놓아도 가져옵니다.

## 저장 구조와 위치
- 모든 문서·분류·태그가 DB 파일 하나(`vault.db`, SQLite)에 있습니다. 기본 위치: `문서\KnowVault\vault.db`. 옵션에서 "위치 바꾸기…"로 다른 폴더로 옮길 수 있고, 옮길 때는 복사 후 확인하고 이전 파일은 그대로 남깁니다. **DB 폴더 자체를 Synology Drive 등으로 동기화하지는 마세요** — 켜져 있는 동안 생기는 `-wal`/`-shm` 파일까지 같이 동기화돼야 해서 중간에 걸리면 꼬일 수 있습니다. PC 간에 주고받으려면 아래 "동기화 저장소"를 쓰세요.
- 검색 색인: 3글자 이상 낱말은 검색 색인(SQLite FTS5)으로 빠르게 찾고, 1~2글자는 전체를 훑습니다. 색인은 쉬는 동안 자동으로 채워집니다.
- DB 정리: DB 파일이 마지막 정리 후 500MB 늘 때마다 시작할 때(하루 한 번) 정리를 권합니다. 빈 공간을 없앤 새 파일로 교체하고 이전 파일은 `backup\compact-날짜.db`에 최근 1개만 보관합니다. 옵션의 "지금 DB 정리…", "검색 색인 다시 만들기"로 직접 실행할 수도 있습니다.
- 자동 백업: 하루 한 번 DB 옆 `backup` 폴더에 복사본(기본 7개 보관). 옵션의 "지금 백업", "백업 폴더 열기".
- 동기화 저장소(날짜별 백업과 별개): 옵션에서 고른 폴더에 "지금 DB 그대로"를 2MB 조각 여러 개로 나눠 두고, 안 바뀐 조각은 다시 쓰지 않습니다(문서 하나를 고쳐도 보통 조각 몇 개만 바뀌어, Synology Drive가 그 조각들만 올리면 됨 — 증분 동기화). 이 폴더를 Synology Drive 등으로 동기화하세요. 동기화 주기(1/3/6/24시간, 기본 24시간)를 옵션에서 고를 수 있고, "지금 동기화"로 바로 갱신할 수도 있습니다. 다른 PC에서는 동기화가 끝난 뒤 옵션의 "이 폴더에서 불러오기"로 그 내용을 가져올 수 있습니다(조각이 덜 도착했으면 알려주고 중단하며, 불러오기 전 상태는 자동으로 백업됩니다).
- **두 PC를 동시에 켜 두는 경우**: 완전히 합쳐 주는 기능은 아니지만, 내가 "지금 동기화"를 누르기 전에 다른 PC가 먼저 올린 게 있으면 모르고 덮어쓰지 않도록 미리 알려주고 확인을 받습니다. 자동 동기화도 이 경우엔 조용히 건너뛰므로(확인창을 띄울 수 없어서), 평소에는 한쪽에서 다 쓰고 닫은 뒤 다른 쪽에서 "이 폴더에서 불러오기"로 가져오는 방식을 권합니다.
- 설정: `%AppData%\KnowVault\config.json`, 오류 기록: 같은 폴더의 `error.log`.
- DB는 표준 SQLite라 DB Browser for SQLite 등으로 열어 볼 수 있습니다.

## 단축키 (워드 방식, 전체 표는 F1)
- 문서: Ctrl+N 새 문서, Ctrl+E / Ctrl+Shift+F 검색, F2 제목, Ctrl+Shift+T 태그 추가, Ctrl+Shift+D 즐겨찾기, Ctrl+Shift+Delete 휴지통, Ctrl+O 가져오기, Ctrl+Shift+S 내보내기
- 서식(편집창): Ctrl+B 굵게, Ctrl+I 기울임, Ctrl+Shift+X 취소선, Ctrl+K 링크, Ctrl+` 코드, Ctrl+Alt+1~6 제목, Ctrl+Shift+L/O/Q 목록/번호/인용, Ctrl+Alt+T 표, Ctrl+Enter 가로줄
- 기타: Ctrl+F 문서 안 찾기, Alt+Shift+↑/↓ 줄 이동, Ctrl+\ 왼쪽 목록 접기, Ctrl+, 옵션, Ctrl+Alt+D 라이트/다크 전환(레이저·사용자 지정은 옵션에서), Ctrl+휠 글자 크기, F1 도움말


## 설치
[Releases](../../releases)에서 `Akashic.exe`를 받아 실행합니다(설치 과정 없음). 이후에는 앱이 새 버전을 확인해 자동으로 내려받아 설치하고, 다시 시작하면 적용됩니다(옵션 > 정보에서 끌 수 있음).

## 빌드
```
cargo build --release     # target\release\akashic.exe
cargo test --release
```
릴리스 빌드는 `AKASHIC_REPO=사용자/저장소` 환경변수가 설정된 경우에만 업데이트 확인이 켜집니다(GitHub Actions가 자동으로 넣음).

## 릴리스 올리기
1. `Cargo.toml`의 `version`을 올린다(예: 2.0.1).
2. `git tag v2.0.1 && git push origin v2.0.1` — Actions가 빌드해 `Akashic.exe`, `SHA256SUMS`를 Releases에 올린다.
